## Advanced looping methods

_In JavaScript we have multiple loops such as while, do while and for but these are the traditional loop, We have some advanced loop as well in JavaScript by which we can simplify the traditional loops. Few of are listed below._

1. **for in:** _It is an advanced looping methods which is generally designed to iterate the objects. In JavaScript generally we can iterate the iterables like arrays, strings etc. But to iterate an object we must and should go with **for in** loop._
2. **for of:** _This is also an advanced looping method and it helps to iterate the iterable object such as string, arrays, date etc. It can't iterate any objects._
