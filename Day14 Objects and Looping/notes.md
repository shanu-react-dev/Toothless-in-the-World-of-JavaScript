## Objects

_Objects are non primitive datatype in JavaScript and it helps to store multiple values in a single variable in the form of key and value pairs. It is mutable in nature._

_There are multiple built in objects in JavaScript such as **Date**, **set** and **map**. It comes up with multiple built in methods as well as follows._

1. **freeze:** _freeze is an object method coming from constructor Object and it allows us to freeze the object after freezing we can't able to modify or add any other properties inside the existing object._

2. **isFrozen:** _This method helps to check whether the particular object is frozen or not. It returns one boolean value if the object is frozen then it will return true else false._

3. **seal:** _This method restrict the users to add any new properties. Here we can able to update the existing properties but we can't add the new properties._

4. **isSealed:** _This property checks whether any object is sealed or not if it is sealed it will return true else false._

5. **keys:** _This method helps to retrieve the entire key name of an object into an array._

## set

_Set is an array like object where we are having multiple values in unique form. It is similar to array but it is not an array. It can be iterated using for of loop._
