## Functions in JavaScript

_Functions in JavaScript is a set of block of reusable codes which is used to perform some specific tasks. It is reusable in nature. There are multiple types of functions in JavaScript as follows._

1. **Named Function:** A function which is having a name known as named function. It can be called anywhere once after declaration. It suppports function hoisting means it will be moved to the top of its current scope.
2. **Anonymous Function:** A function which does not have any name known as anonymous function. Generally it is used to pass as an argument to another function.
3. **Function Expression:** Any function which is stored inside a variable known as function expression. It can be named as well as anonymous function. It will be always called by its variable name.
4. **IIFE (Immediately Invoked Function Expression):** It is a function which will be executed as soon as it has been declared or just after declaration. It can't be stored inside a variable.
5. **Arrow Function:** It is a shorthand function which is used to reduce the syntax of the function. It was introduced in ES6 feature of JavaScript.
6. **HOF (Higher Order Function):** A function which accepts another function as an argument known as Higher Order Function. It can return a new function as well.
7. **Callback Function:** A function which is passed as an argument known as callback function.
8. **Nested Function:** A function created inside another function known as nested function.
9. **Function Currying:** It is a feature of JavaScript by which we can call a nested returned function by just adding one extra parantheses to the parent function.
10. **Generator Function:** It is a function which allows us to pause the function execution and starts the execution from the same point where it was paused.
