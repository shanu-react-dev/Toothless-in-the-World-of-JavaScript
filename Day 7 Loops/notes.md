## Loops

_Loop is a way by which we can execute a task repeatedly until and unless the condition gets false. It is a control flow statement which allows us to perform the task repeatedly. There are multiple loops as follows._

1. **while:** It is an entry control loop which allows us to run the particular task for multiple times until and unless the condition gets false. Here the number of iterations is not defined.
2. **do-while:** It is an exit control loop where the munimum number of iteration is 1. It also executes the code for multiple times until and unless the condition gets false.
3. **for:** This is an exit control loop, where the number of iterations is defined it can have initialization, condition and updation.

## break and continue

_Both are keywords in JavaScript and it is used inside loop. Break keyword is used to break the loop and stop the execution whereas continue keyword is used to skip the iteration._
