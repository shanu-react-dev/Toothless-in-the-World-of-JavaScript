## Links

_Link is also referred as HyperLink, it helps to redirect from one page to another page or resources. In HTML we can create a link using anchor tag `<a></a>`. It accepts attributes like `href`, `target` `download` etc._

## Attributes

1. **`href`:** _`href` stands for Hyper Reference which accepts the path or URL of the resources. It can be absolute path or it can be relative path. **Absolute path** is a path which we are getting from root directory. **Relative path** represents the path where the media files are present in current working directory._

2. **`target`:** _target attribute in anchor tag defines where the link should open here we have values like `_blank`, `_self`, `_parent` and `_top`. By default the value is `_self`, `_blank` helps to open the link in new tab._

3. **`download`:** _download attribute helps to create a downloadable link. Using this link we can able to download the specified resources inside href._

## Media tags

_Media tags in HTML is used to add any media files in our webpages. To add any image, video, audio or any other media resources we will use media tags._

1. **`<img/>`:** img tag is used to add image data in our webpages. It accepts attributes like `src` where we can add the path, `alt` which is used to show the text if the path is incorrect, `height` and `width` to adjust the size of the image.

2. **`<video></video>`:** video tag is used to add the video file in our webpages. It accepts attributes like `controls` to add the play pause button, `autoplay` it helps to play the video automatically after realoading, `loop` helps to play the video repeatively, `muted` helps to play the video in muted state.

3. **`<audio></audio>`:** It helps to add the audio resources in our webpages. whatever the attributes are used in video same attributes will be used here as well.

4. **`<iframe></iframe>`:** Iframe tag helps to add any other HTML resources in our webpages like youtube video or google maps.
