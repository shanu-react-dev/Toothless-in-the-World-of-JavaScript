## Non-Primitive datatypes

_These are reference based datatype. It can store multiple values in a single variable. These are mutable in nature means can be modified._

_There are mainly three Non primitive datatypes in JavaScript as follows._

1. **Array:** _Array is a Non-Primitive datatype and it can store multiple values in a single variable. Here stored values are known as elements each and every element has position as index. Index always starts from 0 and go upto the last element._

_Elements can be accessed using their index value._

_By default in JavaScript arrays are Heterogeneous. Here we can store any kind of datatype in JavaScript array._

2.  **Object:** _Object is a Non-Primitive datatype in JavaScript and helps to store multiple values in the form of key and value pairs. The stored value in the form of key and value pairs known as properties. This is also modifiable. We can access properties by using object name followed by dot `.` symbol with property name._

3.  **Function:** _Function is a block of reusable code which helps to perform some specific task. It is reusable in nature once we declared we can use it anywhere n number of times._
