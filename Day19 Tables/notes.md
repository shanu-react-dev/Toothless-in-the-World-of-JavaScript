## Tables

_Table in HTML is a combination of rows and columns. It is used to show the data in structured or organized way. table is a tag in HTMl is used to create the tables. It comes up with some offset tags to create rows and cells._

## Tags used inside table

1. **`<table></table>`:** _This tag is used to create tables inside this we can use border attribute to add border to the tables._

2. **`<caption></caption>`:** _caption tag is used to add the title for the tables._

3. **`<thead></thead>`:** _This tag helps to store the heading data for the tables. It can contain multiple heading rows._

4. **`<tr></tr>`:** _This tag is used to create rows inside the tables._

5. **`<th></th>`** _By using this tag we can create heading cells inside rows._

6. **`<tbody></tbody>`:** _This tag is used to store the body data for the table._

7. **`<td></td>`:** _This is used to create cells for the body inside tr tag._

## rowspan and colspan

_These two are attributes generally used inside cells tag (`<td></td>, <th></th>`). Both accepts number of cells needs to be merged. rowspan attribute helps to merge the row cells whereas colspan is used to merge the column cells._
