## Advanced array methods

_There are few advanced array methods which helps to transform, filter or loop the array. There are multiple advanced arrat methods listed below._

1. **map:** _map is an advanced array method or it is a higher order function which helps to transform the array elements. It returns one new array with the same length with modified elements. It does not change or modify the actual array._

2. **filter:** _filter is an array method and it accepts one function as an argument and returns one new array with filtered data. It does not modify the actual array._

3. **forEach:** _It is an advanced looping method which helps to iterate the array elements. It does not return anything except undefined. It also does not modify the actual array._

4. **reduce:** _reduce is an advanced array method and generally it is used to perform any mathematical operations on array. It reduces the entire array elements into one single value and returns that. It also does not modify the actual array._
