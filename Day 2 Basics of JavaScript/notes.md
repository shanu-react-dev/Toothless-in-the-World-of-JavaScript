## JavaScript

_JavaScript is a High Level Programming language and Client side Scriptitng Language. It is used to add Functionalities to our webpages. It helps to make the webpages dynamic and Interactive._

_It was introduced in 1995 by Brendan Eich at Sun Micro System (Netscape). Initially it got popular as Mocha later it got renamed as LiveScript and again It got changed as JavaScript just for Marketing strategy. In 1996 it got one competitor as JScript developed by Microsoft. To overcome with the confusion ECMA (European Computer Manufacturer Association) came in the picture and justified JavaScript as a Client Side Scripting language. After that again it got renamed as ECMAScript._

## Features of JavaScript

1. High Level Programming language
2. Client Side Scripting Language
3. Synchronous
4. Interpreted
5. Dynamically Typed
6. Object Based / Partially supports OOPs
7. Weakly or Loosely Typed
8. Open Source
9. Lightweight
10. Large Community (Having multiple libraries and frameworks)

## Tokens

_Tokens are the smallest unit of any programming language. These may be keywords, Identifiers, literals and separators._

### Keywords

_Keywords are reserved or predefined words with special meaning used in multiple ways such as to declare the variables, datatypes, loops etc._

### Identifiers

_Identifiers are varibale names used to store data. Here we have types of the data that is known as datatypes._

### Literals

_Literals are the actual data that will be stored in the variables. It has been categorized in two parts Primitive and Non-Primitive._

### Separators

_Separators are predefined symbol used to provide separation of concern._

### Operators

_Operators are predefined symbol used to perform specific tasks based on operands._

### Rules to declare the identifiers

1. First letter should not be a number or any special characters
2. empty space is not allowed as an identifier
3. Keywords can't be used as an identifier
4. Only `_` and `$` are allowed as an identifier in special characters
5. These are case sensitive.

## DataTypes in JavaScript

_In JavaScript Datatypes are the literals which has been categorized in different types. There are two types of Datatypes in JavaScript._

1. **Primitive Datatypes:** Primitive datatypes are value based datatype. These are immutable in nature and can only store a single value. In JavaScript there are 7 primitive datatypes as follows.
   1. **Number:** _It can store any numeric value whether it is decimal or integer. It can store upto 16 digit numbers._
   2. **String:** _String is a primitive datatype. It is sequence of characters or numbers enclosed within double or single quotes._
   3. **Boolean:** _In boolean we have two values `true` and `false`. It helps to perform conditional statement._
   4. **Null:** _It is a primitive datatype and represents intentionally absence of the value._
   5. **undefined:** _It is also absence of value but here we don't specify intentionally. Whenever a variable is declared but not initialized it will have value as undefined. It is something which can't be defined._
   6. **bigint:** _It is used to store large numbers which can't be stored in `Number` datatype._
   7. **Symbol:** _It is a special datatype and used to make any particular variable as unique._
