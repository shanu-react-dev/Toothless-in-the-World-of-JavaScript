## HTML

_HTML stands for Hyper Text Markup Language. It is a standard Markup language which helps to structure our webpages and helps to add the resources like audio, video, text data in our webpages._

_It was introduced in 1991 by Tim Berners Lee._

## HyperText

_A text which contains some data. In terms of HTML tags are considered as HyperText because it contains the data how to show the elements inside the browser._

## Markup Language

_A language by which we can structure our webpages. It is used to design the schema or sturucture of the webpages._

## Tags

_In HTML tags are predefined and it is enclosed within angular braces. Any text written enclosed within angular braces known as tags._

_Although we can write our own tag but it will not have any meaning. It will be considered as normal text in the browser. By default in HTML every text will have 16px size._

_There are two types of tags in HTML as follows._

1. **Paired tags:** _Paired tags are the tags where we have opening tag as well as closing tag together known as paired tags._
2. **Unpaired tags:** _Unpaired tags in HTML is a tag where we have either opening tag or closing tag. It is also known as self closing tag._

## elements

_Any text or content written enclosed within opening tag and closing tag known as an element._

## Attributes

_Attributes are keywords which helps to provide additional information to the elements or tags. There are two types of attributes as follows._

1. **Global Attributes:** _Global attributes are the attributes which can be used on any other tags. e.g. `class, id, title etc.`_
2. **Element Specific Attributes:** _These are the attributes which will be used only on the specific element like `href`, `charset` etc._

_Attributes will be always used inside opening tags._
